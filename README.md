## 💎 Core Highlights

### 🔊 1. Procedural Web Audio Synthesis
* **No audio files (`.mp3` / `.wav`)** — zero latency, zero bandwidth bloat.
* **Frequency Modulation & White Noise Buffers**:
  * Mechanical key switch clicks on every digit pressed.
  * Ultrasonic NFC card tap confirmation chimes.
  * Stepper motor mechanical hum during thermal printing.
  * High-fidelity paper tearing friction bursts.
  * Low-end solenoid power thuds on system boot and shutdown.

### 💳 2. Dual Payment Engine
* **Contactless Card Tap (NFC)**:
  * Glowing beacon card pod with dynamic LED state machine.
  * Interactive card tap simulation with instant validation & authorization.
* **UPI Dynamic QR Code**:
  * Crisp SVG-rendered matrix QR with embedded payment payload.
  * Instant auto-polling simulation and verification.

### 🧾 3. Interactive Mechanical Receipt
* Real-time thermal printing animation with realistic line-by-line emergence.
* Authentic zigzag cut serration with physics tear animation.
* Modal view offering itemized details, transaction metadata, and direct PDF / paper printing.

### 🕹️ 4. Secret 1987 CRT Retro Mode
* Complete throwback phosphor-green scanline CRT aesthetics.
* Vintage mainframe font rendering and mechanical relay audio profile.

## ⌨️ Desktop Keyboard Mastery

Use your physical keyboard like a hardware engineer:

| Key Binding | Physical Action | Sound Trigger |
|:---:|:---|:---|
| <kbd>0</kbd> – <kbd>9</kbd> | Type amount or card PIN | Tactile micro-switch click |
| <kbd>Enter</kbd> | Confirm amount / Authorize | High-pitch POS confirmation beep |
| <kbd>Backspace</kbd> | Clear input buffer (`CLR`) | Mechanical release chirp |
| <kbd>C</kbd> | Tear printed receipt paper | Perforated paper rip burst |
| <kbd>N</kbd> | Initialize brand-new session | Dual-relay power reset sound |

## 🚀 Instant Launch

```bash
# 1. Grab the repository
git clone https://github.com/your-username/foxy-pay.git

# 2. Enter the cockpit
cd foxy-pay

# 3. Install dependencies
npm install

# 4. Ignite the terminal
npm run dev
```

Open **`http://localhost:3000`** in any modern browser to start interacting.
